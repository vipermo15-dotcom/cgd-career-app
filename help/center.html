재학생 취업시스템 — 공동훈련센터용 안내 ← 화면으로

접속: https://vipermo15-dotcom.github.io/cgd-career-app/ (이메일 매직링크 로그인, 비밀번호 없음)

1. 시스템 개요

  • 목적: 수료를 앞둔 기수의 취업 진행상황과 실적을 하나의 데이터 흐름으로 관리 (희망직무 → 역량 진단 → 채용공고 매칭 → 부족역량(GAP) → 지원 → 취업 결과 → 성과 지표)
  • 사용자 역할: 관리자 / 강사 / 교육생 / 공동훈련센터(팀장·담당 center_lead). 역할별로 볼 수 있는 범위와 할 수 있는 일이 분리됩니다.
  • 운영 형태: 웹앱(PC·모바일). 별도 설치 없음.

2. 공동훈련센터 계정

이 시스템은 공동훈련센터 팀장·담당(center_lead) 계정만 열람·이용할 수 있습니다. 그 외 인원(본부 등)은 이 시스템으로 직접 보지 않으며, 필요한 내용은 학과를 통해 별도로 전달받습니다.

역할 대상 할 수 있는 일
center_lead (팀장·담당) 팀장·채용 담당자 DASHBOARD·성과보고·주차현황·업체현황 열람 + 업체 등록 + 취업자 등록(등록만 — 확정은 여전히 관리자만)

역할은 관리자가 회원 탭에서 지정합니다. 로그인하면 자동으로 이 화면으로 이동하며, 다른 화면(학생 상세, 회원 관리 등)은 열리지 않습니다.

로그인 시 개인정보 보호정책 확인

새 로그인 세션마다(브라우저를 닫았다 다시 열면) 개인정보 보호정책 안내 창이 뜹니다. 체크박스를 확인해야 화면을 쓸 수 있으며, 확인한 기록은 감사 로그로 남습니다.

3. 개인정보 처리 (핵심)

항목 처리 방식
학생 연락처·주민번호·주소 DB에 저장하지 않음
학생 이름 표시용 이름을 DB에 저장하고 담당 강사·관리자와 본인만 열람합니다. 공동훈련센터 화면(DASHBOARD·성과보고·주차현황·업체현황)에는 실명이 노출되지 않고 번호(S01~S21)만 나옵니다.
취업처 담당자 연락처 업체·취업자 등록 시 입력하는 기업측 채용 담당자 연락처입니다. 학생 개인정보가 아니라 별도로 저장·표시됩니다.
업로드 문서(이력서·자소서 등) 학생이 민감정보 제거본만 업로드하도록 강제(체크 필수). 본인·담당 강사만 열람
접근 통제 이메일 인증(비밀번호 없음) + 역할 기반 행(行) 수준 보안(RLS)
변경 이력 모든 등록·변경이 활동 로그로 자동 기록
백업 Supabase 자동 백업 7일 보관

4. 화면 구성 (4~5개 탭)

DASHBOARD (기본 화면)

  • 주간 취업 KPI: 보고 대상·취업 확정(공식)·검증 대기·취업률·이번 주 신규 입사
  • 이번 주 구직활동(직무별 지원·면접), 최근 12개월 취업 시기
  • 취업 후 사후지도: 고용보험·고용계약서 확인 여부, 재직 상태 분포
  • 사후관리 임박 목록, 최근 특이사항(학과장·강사가 남긴 메모 — 실명 없음)
  • 카드나 목록 항목을 클릭하면 관련 탭으로 바로 이동합니다.

성과보고

보고서 내용
학과장 운영보고 핵심 지표 + 성과 분포 + 데이터 검증 결과 + 오늘의 업무
공동훈련센터 보고 핵심 지표 + 성과 분포 + 학생별 명세(번호 기준)
기관 제출용 요약 핵심 지표 + 성과 분포 + 검증 결과. 미해소 항목이 있으면 「자료보완 필요」 표시
  • 모든 보고서에 기간·기준일·생성일이 표시되며, HTML/CSV로 내려받을 수 있습니다.
  • 취업 확정 = 관리자가 증빙(재직증명서·근로계약서·4대보험 등)을 확인한 건만 포함합니다.
  • 성과 분포: 취업 확정 / 미취업 / 보류 / 취업불가 / 취업거부 / 연락불가 / 자료 미입력(미취업으로 계산하지 않음).
  • 90일 성과는 수료일 + 90일 기준, 사후관리는 수료일 +30일·+90일에 재직 여부·고용계약서·고용보험 가입·취업 유지를 확인합니다.
  • 관리 대상 인원 21명 기준이며, 취업률 분모(대상자·수료자·재적자)는 기관 지침 확인 후 관리자가 설정합니다.

주차현황

주차별로 교육생별 지원·면접·자료 건수, 최근 면접 결과, 취업 후 관리 상태, 진로지도 기록을 번호순으로 봅니다. 열람 전용이며 기록 입력 기능은 없습니다.

업체현황

관리자 검증을 마친 취업자 전원의 업체·직무·입사일·계약서·보험·재직상태·증빙을 봅니다. center_lead 계정에는 「+ 취업 확정 등록」 버튼이 추가로 보입니다.

업체 등록 (center_lead 전용 탭)

기업명·산업·규모·웹사이트·비고·협약기업 여부를 등록합니다. 같은 기업명으로 다시 등록하면 정보가 갱신됩니다.

5. center_lead — 취업자 등록 방법

「업체현황」 탭 → 「+ 취업 확정 등록」에서 다음을 입력합니다.

  • 학생(이름/번호), 취업처, 직무명, 직무분야, 고용형태(정규직·계약직·인턴 중 선택), 입사(예정)일
  • 채용 담당자 연락처(기업측, 필수), 협약기업 등록 여부, 특이사항

등록만으로는 취업이 확정되지 않습니다. 취업률에는 관리자가 증빙을 확인해 검증한 건만 반영됩니다. 등록 시스템 자체가 확정 기능을 갖고 있지 않아(검증 항목이 아예 없음), 관리자 확인 없이는 어떤 방법으로도 확정될 수 없습니다.

6. center_lead — 학생별 활동 기록

「업체현황」 탭 하단에서 학생을 선택해 상담·연계 활동 내용을 남길 수 있습니다. 학과·본부에서 함께 열람합니다.

7. 학과·공동훈련센터 취업 성사 현황

DASHBOARD에 학과·공동훈련센터가 각각 성사시킨 취업 인원이 표시됩니다. 어느 쪽이 등록했는지는 등록한 계정 기준으로 자동 기록되며 별도로 바꿀 수 없습니다.

8. 정기 보고

  • 성과보고 탭의 HTML/CSV 내보내기 → 번호 기준 자료
  • 보고 자료에는 실명이 없어 학과 회의·본부 보고 자료로 그대로 사용 가능
  • 필요 시 담당 강사가 실명 대조표를 별도 첨부(대면·보안 채널)

9. 지표 해석 유의사항

  • 준비도(Readiness)·매칭 점수는 취업 성공을 보장하는 예측치가 아니라, 교육기관이 현재 준비 상태를 비교·관리하기 위한 내부 지표입니다.
  • 점수 가중치는 관리자가 조정할 수 있으므로, 기수 간 비교 시 가중치 변경 여부를 함께 확인하세요.
  • "취업 확정"은 실제 입사·증빙을 확인한 뒤 관리자가 검증해야 반영됩니다(자동 확정·AI 확정 없음).
  • 학생은 항상 번호순으로만 나열됩니다. 순위·취업 가능성 예측은 이 시스템에 없습니다.
