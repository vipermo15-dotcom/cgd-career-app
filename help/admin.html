접속: https://vipermo15-dotcom.github.io/cgd-career-app/

1. 로그인

  1. 위 주소 접속
  2. 관리자 이메일 입력 → 로그인 링크 받기
  3. 메일의 링크 클릭 → 링크를 클릭한 브라우저에서 시스템 사용 (세션이 그 브라우저에 생김)
  4. 관리자로 지정돼 있으면 자동으로 DASHBOARD(관리자 기본 화면)으로 진입. 상단 "홈" 으로 언제든 첫 화면으로 돌아올 수 있고, "강사 화면 →" 로 강사 대시보드를 왕복할 수 있습니다.

2-1. 성과보고 · 취업 검증

강사 화면 탭: 현황 · DASHBOARD · 주차현황 · 업체현황 · 실적 · 학생 · 사후관리 · 성과보고 · 공고 · 명단

원칙

  • 취업은 관리자 검증을 마친 건만 취업률에 포함됩니다. 등록만 된 건은 「검증 대기」입니다.
  • 취업자 등록 경로가 여러 개(학생 상세 / 업체현황 빠른등록 / 공동훈련센터 등록)여도 확정 권한은 항상 관리자뿐입니다. 등록 기능 자체에 검증 항목이 없어 다른 역할은 아무리 시도해도 확정할 수 없습니다.
  • 자료 미입력·연락불가는 미취업이 아닙니다. 미취업은 확인 후 명시한 경우만 분류됩니다.
  • 기관 취업 인정기준을 확인해 「기관 기준 확인 완료」를 체크하기 전까지 모든 보고서에 **「자료보완 필요」**가 표시됩니다.
  • 보고서·DASHBOARD 수치는 하나의 원본(cgd_final_report)에서만 나옵니다. 기준일과 생성일이 항상 표시됩니다.
  • 학생 순위·취업 가능성 예측·출석 기반 취업 판정·자동 취업 확정·자동 지원은 하지 않습니다. 목록은 항상 번호순입니다.
  • 90일 성과 기준일 = 수료일 + 90일 (9/22 수료 → 12/21). 사후관리는 수료일 +30일(10/22), +90일(12/21).

2-2. 공동훈련센터 계정

이 시스템은 공동훈련센터 팀장·담당(center_lead) 계정만 열람할 수 있습니다. 회원 탭에서 역할을 center_lead로 지정하면 DASHBOARD·성과보고·주차현황·업체현황 열람 + 업체 등록 + 취업자 등록(등록만, 확정은 여전히 관리자만)이 가능합니다. 그 외 인원은 이 시스템으로 직접 보지 않습니다.

자세한 안내는 매뉴얼-공동훈련센터.md 참고.

3. 핵심 운영 작업

3-1. 학생 계정 연결

학생이 본인 이메일로 1회 로그인하면 계정이 생깁니다. 그 뒤 SQL Editor에서:

select link_student('학생이메일@example.com', 'S07');

여러 명 한 번에:

select link_student(email, code) from (values
  ('a@x.com','S01'), ('b@x.com','S02')   -- 로그인한 학생만
) v(email, code);

→ 연결되면 그 학생은 다음 로그인부터 학생 화면으로 들어갑니다. → 회원 탭에서 로그인한 계정을 수시로 확인하고 연결하세요.

3-2. 강사·공동훈련센터 계정 추가

새 계정이 1회 로그인 → 회원 탭에서 역할을 instructor/center_lead 중 지정·저장.

3-3. 새 기수 시작

강사 화면 상단바 → + 새 기수 → 이름·수료일·대상인원 입력. 학생은 명단 탭에서 CSV/JSON 붙여넣기로 일괄 등록(번호 부여).

4. 정기 관리

  • 백업: Supabase 대시보드 → Database → Backups (무료 플랜 7일 보관). 중요 시점엔 Table Editor → Export CSV 수동 백업
  • 현황 보고: 성과보고 탭의 HTML/CSV 내보내기 (번호 기준, 실명 없음)
  • 가중치 튜닝: 실제 매칭 결과가 감과 다르면 설정 탭에서 조정

5. AI 기능 켜기 (선택)

현재 AI 3종(공고분석·코치·포폴평가)은 미배포. 켜려면:

cd 취업시스템-web
npx supabase login
npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-xxxx --project-ref hpzpojvywpqputbzfwqo
npx supabase functions deploy job-analyze       --project-ref hpzpojvywpqputbzfwqo
npx supabase functions deploy career-coach      --project-ref hpzpojvywpqputbzfwqo
npx supabase functions deploy portfolio-analyze --project-ref hpzpojvywpqputbzfwqo

Anthropic API는 Claude 구독과 별개 유료(기수당 대략 ₩1천~7천, 신규 계정 $5 무료크레딧).

6. 문제 대응

증상 원인 / 조치
"계정 준비 중" 화면 profiles에 역할 미지정 → 회원 탭에서 역할 부여 또는 link_student
로그인이 안 됨 매직링크를 다른 브라우저에서 클릭함 → 앱 쓸 브라우저에서 다시 로그인
AI 버튼 "미설정" Edge Function 미배포 (정상). 5번 참고
매직링크 메일 안 옴 스팸함 확인. Supabase 무료 플랜은 시간당 발송 제한 있음 → 잠시 후 재시도
스키마 재적용 필요 supabase/_deploy_all.sql 전체를 SQL Editor에 실행 (멱등, 데이터 보존)
SQL Editor에서 "Success" 인데 실제로 반영 안 됨 긴 SQL을 붙여넣을 때 중간이 잘린 경우가 있었음 — 실행 후 select proname from pg_proc where proname='...' 같은 진단 쿼리로 반드시 재확인
