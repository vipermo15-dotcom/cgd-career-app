# 직무별 SNS 신뢰 계정 화이트리스트

> 관련 문서: [`sns-job-posting-research-prd.md`](./sns-job-posting-research-prd.md) 5.1절
> 기준 직무 카테고리: `js/data.js`의 `JOB_CATEGORIES` (AD/ED/GD/BD/PD/MD/SC/CM/BX/CC/AIC)
> 각 직무는 개별 리서치를 거쳐 이 표에 추가되며, 아직 리서치하지 않은 직무는 "조사 예정"으로 표시한다.

## 사용 원칙
- 재수집 시 일반 키워드 검색보다 **이 표의 계정을 지정한 검색**(`"{계정명} 채용"`)을 우선 사용 (Phase 5에서 실증된 기법)
- 직무별로 주력 플랫폼이 다르므로, 노이즈 비율이 높은 플랫폼은 화이트리스트 계정 검색으로 전환하거나 제외
- 표는 실행할 때마다 최신 결과로 갱신 (완전한 목록이 아니라 실증된 것만 등재)

## Threads·X 공통 큐레이터 (직무 무관, 신규 발견 — 중요)

BD·PD를 Threads/X까지 완전히 검증하는 과정에서, **Threads와 X는 Instagram/Facebook과 달리 "직무별 전문 계정"이 아니라 "전 직무를 다루는 소수의 파워 큐레이터"가 신호를 지배**한다는 패턴을 확인했다. 동일한 계정이 BD·PD·GD·UXUI 등 서로 다른 쿼리에서 반복적으로 상위 노출됨:

- **remaincareer** (Threads) — 주간 디자이너 채용 정보 업데이트, 직무 무관
- **owanimal** (Threads) — "채용 공고로 보는 필요 역량" 분석 + 실제 공고 인용, 직무 무관
- **인디스워크 / inthiswork / @INTHISWORK1** (Threads + X 동시 운영) — 채용공고 큐레이션, 직무 무관
- **chchalarm** ("취준생을 위한 알림", X) — 주간 채용 공고 모음, 직무 무관
- **김군 / @ouyi5e34N6Zv9zb** (X) — 개인이 운영하는 채용정보 게시 계정, 지역·직무 다양

**결론**: Threads·X 재수집 시에는 매번 새 직무 키워드로 일반 검색을 반복하기보다, **위 5개 계정을 지정한 검색으로 전환하는 것이 훨씬 효율적**이다. 이는 Instagram/Facebook의 화이트리스트가 "직무별 직접 게시 기업 계정" 위주인 것과 대조된다 — 플랫폼 구조 자체가 다르기 때문으로 해석된다(Threads/X는 재게시·큐레이션형 콘텐츠가 우세, Instagram/Facebook은 기업 공식 계정의 직접 게시가 상대적으로 활발).

## 종합 관찰 (BD·PD 다중 플랫폼 검증 + 전 카테고리 Instagram 1차 리서치 종합)
- **Instagram/Facebook**: 직무별 신호가 뚜렷이 다르고(예: ED는 FB가 강함, 나머지는 IG가 강함), 신뢰 계정도 직무마다 달라 카테고리별 관리가 유효함.
- **Threads/X**: 위에서 확인했듯 신뢰 계정이 직무를 가리지 않고 동일 인물/계정으로 수렴함 → **직무별로 별도 관리할 실익이 낮음**, 대신 위 "Threads·X 공통 큐레이터" 목록 하나를 모든 직무에 공통 적용
- 카테고리를 막론하고 반복 등장하는 범용 큐레이션 계정: **디자인루키, 윤빌리티**(IG/FB), **remaincareer, owanimal, 인디스워크, chchalarm, 김군**(Threads/X)
