# 직무별 SNS 신뢰 계정 화이트리스트

> 관련 문서: [`sns-job-posting-research-prd.md`](./sns-job-posting-research-prd.md) 5.1절
> 기준 직무 카테고리: `js/data.js`의 `JOB_CATEGORIES` (AD/ED/GD/BD/PD/MD/SC/CM/BX/CC/AIC)
> 각 직무는 개별 리서치를 거쳐 이 표에 추가되며, 아직 리서치하지 않은 직무는 "조사 예정"으로 표시한다.

## 사용 원칙
- 재수집 시 일반 키워드 검색보다 **이 표의 계정을 지정한 검색**(`"{계정명} 채용"`)을 우선 사용 (Phase 5에서 실증된 기법)
- 직무별로 주력 플랫폼이 다르므로, 노이즈 비율이 높은 플랫폼은 화이트리스트 계정 검색으로 전환하거나 제외
- 표는 실행할 때마다 최신 결과로 갱신 (완전한 목록이 아니라 실증된 것만 등재)

## 종합 관찰 (전 카테고리 리서치 완료 후)
- **Instagram이 디자인 계열 전 직무에서 일관되게 강한 신호(8~10/10)**를 보임 — 편집디자인(ED)만 예외적으로 Facebook이 더 강했음. 재수집 스케줄의 기본 플랫폼은 Instagram으로 설정하고, ED만 Facebook을 우선하는 것을 제안.
- 이번 라운드는 카테고리당 Instagram 1개 쿼리만 검증했으므로, Threads/Facebook/X에서의 정확한 신호/노이즈 비율은 카테고리별로 추가 검증이 필요하다 (ED/GD/UXUI만 다중 플랫폼 비교 완료).
- 카테고리를 막론하고 반복 등장하는 범용 큐레이션 계정: **디자인루키, 윤빌리티** — 특정 직무 전용이 아니라 전 직무 공통 우선 소스로 유지.
