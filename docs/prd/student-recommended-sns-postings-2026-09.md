# 교육생 추천 SNS 채용공고 리스트 (2026-09-13 기준)

> 목적: 첨부된 교육생 희망 채용공고(브랜드/BI·BX, 그래픽·편집, 패키지, VMD, 병원 마케팅)와 동일한 5개 분야를 인스타그램·스레드·페이스북·X에서 정밀 리서치해, 신입 기준·서울/경기 기준·마감 전 공고를 추천 리스트로 정리
> 방법: `job-category-trusted-accounts.md`의 검증된 채널(직무별로 Instagram/Facebook 우선)을 활용해 Firecrawl 검색 실행

## ⚠️ 반드시 읽어야 할 제약사항

1. **원문 직접 확인 불가**: 이 실행 환경은 Instagram/Facebook/X/Threads 도메인에 직접 접속이 차단되어 있어(Phase 5 확인), 아래 공고는 **검색 스니펫에 포함된 정보만으로 판단**했습니다. 스니펫에 마감일이 명시된 경우만 "마감 전"으로 확신할 수 있고, 명시되지 않은 경우 게시물 문맥(예: "이번 주 채용", "상시채용")으로 추정했습니다.
2. **지원 직전 원문 재확인 필수**: 아래 모든 링크는 지원 전 학생이 직접 열어 마감 여부·정확한 자격요건을 재확인해야 합니다.
3. **분야별로 확보된 개수가 다름**: 마감된 공고, 신입 요건 불일치(경력 3년 이상 등), 서울/경기 외 지역 공고를 제외하다 보니 일부 분야는 10개를 채우지 못했습니다. 이는 "SNS에 신입·서울경기 기준 공고 자체가 그 정도로만 존재한다"는 실제 리서치 결과이며, 억지로 채우지 않았습니다.
